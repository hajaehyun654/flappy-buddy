# Flappy Buddy 🐥🎮

귀엽고 통통 튀는 캐릭터 **Buddy**와 함께 장애물을 피하며 최고 점수에 도전하는 클래식 스타일의 HTML5 캔버스 웹 게임입니다.

---

## 🌟 주요 특징
- **단일 파일 독립 실행**: 외부 이미지나 외부 사운드 라이브러리 없이 순수 HTML5, CSS3, JavaScript 및 Web Audio API로 구현되어 `index.html` 단독으로 바로 플레이 가능합니다.
- **반응형 디자인**: 데스크톱(키보드/마우스)과 모바일(터치) 완벽 지원.
- **풍부한 시각 효과**: 낮/밤 변화 느낌, 부드러운 패럴랙스 배경, 점수 획득 파티클, 충돌 애니메이션.
- **자체 신디사이저 사운드**: Web Audio API를 활용한 점프, 스코어 획득, 충돌, 버튼 클릭 효과음 탑재.
- **최고 점수 저장**: LocalStorage를 이용한 최고 기록 영구 보존.

---

## 🕹 조작 방법
- **점프 (위로 날기)**:
  - 데스크톱: `스페이스바(Space)`, `화살표 위(↑)`, 또는 화면 마우스 좌클릭
  - 모바일/태블릿: 화면 터치
- **일시정지**: 화면 우측 상단 `일시정지(❚❚)` 버튼 클릭 또는 `P` 키
- **소리 켜기/끄기**: 화면 우측 상단 `스피커(🔊)` 버튼 클릭

---

## 📂 실행 방법
1. `index.html` 파일을 더블 클릭하여 크롬, 엣지 등 모던 브라우저에서 바로 실행합니다.
