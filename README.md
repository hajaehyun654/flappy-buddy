# Flappy Buddy 🐥🎮

귀엽고 통통 튀는 캐릭터 **Buddy**와 함께 장애물을 피하며 최고 점수에 도전하는 클래식 스타일의 HTML5 캔버스 웹 게임입니다.

---

## 🚀 온라인 플레이 (Cloudflare Pages v1.0)
- **공식 서비스 URL**: [https://flappy-buddy-33w.pages.dev](https://flappy-buddy-33w.pages.dev)

---

## 🌟 주요 특징 (v1.0)
- **단일 파일 독립 실행**: 외부 이미지나 외부 사운드 라이브러리 없이 순수 HTML5, CSS3, JavaScript 및 Web Audio API로 구현되어 `index.html` 단독으로 바로 플레이 가능합니다.
- **파이프 난이도 다양화**: 좁은 간격(스릴)부터 넓은 간격(여유)까지 매번 다채롭게 생성되는 파이프 간격.
- **생명 시스템 & 무적 모드**: 총 3개의 목숨 제공, 피격 시 반투명 깜빡임 + 무지개 배경 전환 + 일시적 장애물 무적 통과.
- **여분의 목숨 (빨간색 하트)**: 5의 배수 파이프마다 상하 파이프 사이에 스폰되는 붉은 하트 아이템 (최대 3개 유지).
- **반응형 디자인**: 데스크톱(키보드/마우스)과 모바일(터치) 완벽 지원.
- **풍부한 시각 효과**: 낮/밤 테마 모드, 매 1점마다 캐릭터 컬러 변신, 패럴랙스 배경, 충돌 및 스파클 파티클.
- **자체 신디사이저 사운드**: Web Audio API를 활용한 점프, 스코어 획득, 충돌, 버튼 클릭, 생명 회복 효과음 탑재.
- **최고 점수 저장**: LocalStorage를 이용한 최고 기록 영구 보존.

---

## 🕹 조작 방법
- **점프 (위로 날기)**:
  - 데스크톱: `스페이스바(Space)`, `화살표 위(↑)`, 또는 화면 마우스 좌클릭
  - 모바일/태블릿: 화면 터치
- **낮/밤 테마 전환**: 화면 우측 상단 `해/달(☀️/🌙)` 버튼 클릭 또는 `N` 키
- **일시정지**: 화면 우측 상단 `일시정지(❚❚)` 버튼 클릭 또는 `P` 키
- **소리 켜기/끄기**: 화면 우측 상단 `스피커(🔊)` 버튼 클릭 또는 `M` 키
